## GitHub Pages 線上展示版

展示網址：[https://micha1lyu.github.io/_se/HW2/](https://micha1lyu.github.io/_se/HW2/)

網站提供學生與教師示範登入、課表、加退選、成績草稿與公布、成績匯出及聯絡資料更新。**線上版為純前端模擬，不執行 Node.js 或 SQLite**；資料存在此網站的瀏覽器 `localStorage`，登入狀態存在分頁的 `sessionStorage`。同一瀏覽器切換學生／教師或開另一分頁可查看相同資料，不同電腦、不同瀏覽器不會共用。重新整理會保留資料，上方「重設示範資料」可回復初始狀態。

```powershell
npm run build:pages
npm test
```

## 快速啟動

電腦需有 **Node.js 22.13 以上版本**（建議使用本機已安裝的 Node.js 24）。不需要 `npm install`，也不需要另外安裝資料庫。

1. 在專案資料夾雙擊 `start.bat`，或在終端機執行：

   ```powershell
   cd "C:\Users\user\Desktop\現代軟體工程\HW2"
   npm start
   ```

2. 瀏覽器開啟 **http://localhost:3000**。
3. 點「帶入示範帳號」，再登入。

登入頁可切換「學生專區」與「教師專區」。教師示範帳號為 **`t001` / `Teacher1234!`**（王思涵，教授 CS202 現代軟體工程）；另一組教師 **`t002` / `Teacher1234!`**（林志遠，教授 CS201 資料結構）可用來驗證授課權限隔離。學生帳號如下，密碼未變更。

| 欄位 | 示範值 |
| --- | --- |
| 學號 | `s113001` |
| 密碼 | `Demo1234!` |
| 學生 | 陳以安／資訊工程學系二年級 |

請保留啟動視窗；結束時按 `Ctrl+C`。請經由 HTTP 網址使用，不能直接雙擊 `public/index.html`。

若 3000 已被使用，可在 PowerShell 執行 `$env:PORT=3001; npm start`，改開 http://localhost:3001。

## 功能

| 頁面 | 可實際操作的功能 |
| --- | --- |
| 校務總覽 | 顯示本學期學分、課程數、歷年加權平均、公告與服務捷徑 |
| 我的課表 | 每週課表隨加退選更新，可列印或用瀏覽器另存 PDF |
| 學期成績 | 篩選歷年學期、自動計算學分及加權平均、匯出含 UTF-8 BOM 的 CSV |
| 選課作業 | 依課程、代碼、教師搜尋，分類篩選，加選、確認退選 |
| 個人資料 | 顯示唯讀學籍、驗證並儲存電子郵件與電話 |
| 校園公告 | 列出公告、開啟完整內文 |
| 帳號 | 登入、登出、重新整理後維持登入，8 小時後 Session 到期 |

固定示範學期為 **114 學年度第 1 學期**，不代表電腦目前日期或學校實際行事曆。示範平均為學分加權百分制，未換算 GPA。

### 可展示的操作情境

1. 登入後查看初始的 5 門課、12 學分。
2. 加選 `CS204 網頁程式設計`，回首頁與課表確認變成 6 門、15 學分。
3. 加選 `CS205 人工智慧概論`，系統提示與現代軟體工程衝堂。
4. 加選 `GE202 海洋與永續發展`，系統提示額滿。
5. 退選 CS204，確認課表、學分與剩餘名額同步更新。
6. 更新聯絡資訊，重新整理驗證資料仍在。
7. 篩選 `113-2` 成績，再匯出 CSV。
8. 登出後重新整理，回到登入畫面。

初始課程會在第一次啟動時建立。每次加退選均會檢查重複、容量、同日節次重疊及 25 學分上限；示範允許退選未公布成績的必修，未加入擋修、最低學分、選課日期與真實學籍規則。已公布成績的課程不可由學生自行退選；未公布的草稿會在學生退選時清除。

## 技術與結構

```text
HW2/
├── package.json          指令與 Node.js 版本要求
├── server.js             HTTP API、驗證、SQLite 與初始示範資料
├── start.bat             Windows 啟動入口
├── public/
│   ├── index.html        HTML 頁面入口
│   ├── app.js            前端導覽與互動
│   ├── teacher.js        教師介面、雙身分登入、學生名單與成績管理
│   └── styles.css        桌面、手機與列印樣式
├── tests/
│   ├── system.test.js    HTTP 與資料庫整合測試
│   ├── teacher.test.js   教師權限與成績公布整合測試
│   └── migration.test.js 舊資料庫保留與升級測試
├── data/                 首次啟動後自動產生，已加入 .gitignore
│   └── campus.sqlite     SQLite 資料庫
└── README.md
```

前端採 HTML、CSS 與原生 JavaScript；後端採 Node.js 內建 HTTP、Crypto 與 `node:sqlite`。SQLite 在部分 Node.js 版本會顯示 ExperimentalWarning，這不影響啟動。

前端呼叫 JSON REST API；伺服器驗證後以參數化 SQL 存取 SQLite。加退選在資料庫交易中完成，以確保名額檢查與寫入一致。前端文字會 HTML 轉義，避免示範聯絡資訊被當成 HTML。

## API

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| POST | `/api/login` | `{id,password}` 登入並設定 Cookie |
| POST | `/api/logout` | 刪除 Session 與 Cookie |
| GET | `/api/dashboard` | 取得目前學生、公告、課程、成績 |
| PUT | `/api/profile` | `{email,phone}` 更新聯絡資料 |
| POST | `/api/enrollments/:courseId` | 加選課程 |
| DELETE | `/api/enrollments/:courseId` | 退選課程 |

除登入之外皆需要有效 Session。修改請求使用 JSON，錯誤以適當 HTTP 狀態碼及 `{error:訊息}` 回傳。

## 資料表

- `students`：學生學籍、聯絡資訊、隨機 salt 與 scrypt 密碼雜湊。
- `courses`：課程、時間、教室、容量及虛構其他學生已占名額 `occupied`。
- `enrollments`：學生與課程關聯，以聯合主鍵避免重複選課。
- `grades`：已公布的歷年成績。
- `announcements`：校園示範公告。
- `sessions`：隨機登入 Token、學生與有效期限。

顯示已占名額為 `occupied + enrollments 筆數`。教師名單只顯示資料庫中的具名學生，目前預設一位；`occupied` 是容量展示的虛擬占用名額，並無對應學生帳號。專案提供學生與教師介面，未實作管理員介面。

## 教師專區與成績流程

| 頁面 | 功能 |
| --- | --- |
| 教學總覽 | 本學期授課數、實際修課人次、待公布成績筆數與授課捷徑 |
| 我的授課 | 本人授課時間、教室、學分、人數與已公布進度 |
| 修課學生 | 依授課課程查看學生學號、姓名、學系與年級 |
| 成績登錄 | 輸入 0–100 整數、儲存草稿、確認公布、修改後再次公布 |
| 授課課表 | 教師本人的每週授課安排，可列印 |
| 教師資料 | 查閱教師帳號與職稱，更新聯絡資訊 |
| 校園公告 | 閱讀全校公告 |

### 教師到學生的完整展示

1. 登出學生，登入頁選「教師專區」，以 `t001` 登入。
2. 從「我的授課」查看 CS202 現代軟體工程，進入「學生名單」。
3. 到「成績登錄」，輸入陳以安的成績，例如 `92`，按「儲存草稿」。
4. 此時學生端仍看不到新成績；按「公布已儲存成績」並確認。
5. 登出教師，切換學生身分以 `s113001` 登入，在學期成績篩選 `114-1`，查看該筆成績。
6. 教師再次修改草稿時，學生仍會看到上一次公布的分數，直到教師再次公布。

必須先儲存完整班級的成績才能公布；可分次儲存草稿，空白代表本次略過、不會刪除既有草稿。0 分是有效成績。公布為整門課的目前實際修課名單，不會產生重複成績。若頁面上有尚未儲存的修改，系統會要求先儲存再公布。

### 新增資料表與 API

- `teachers`：教師帳號、職稱、聯絡資料與密碼雜湊。
- `teacher_courses`：教師與授課課程的明確關聯，後端據此檢查權限。
- `teacher_sessions`：教師專屬 Session；既有學生 Session 保持相容。
- `course_grades`：以課程、學生、學期為聯合主鍵；`score` 儲存草稿，`published_score` 儲存最後公布值。學生 API 只回傳已公布分數。

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| POST | `/api/login` | 新增可選 `role: "student"` 或 `"teacher"`，省略時視為學生 |
| GET | `/api/dashboard` | 依 Session 身分回傳學生或教師資料，並附 `role` |
| GET | `/api/teacher/courses/:id/roster` | 本人授課的實際修課名單與草稿／公布分數 |
| PUT | `/api/teacher/courses/:id/grades` | `{grades:[{studentId:"s113001",score:92}]}` 儲存草稿 |
| POST | `/api/teacher/courses/:id/publish` | `{}` 確認公布已儲存成績 |

後端獨立驗證角色與授課關聯，學生不能呼叫教師 API，教師不能加退選，也不能讀取或修改其他教師的課程。成績儲存與公布均使用交易，驗證失敗會整批回滾。

### 既有資料升級

停止舊版伺服器後執行新版 `npm start` 即會自動新增教師資料表與示範帳號。**不需要刪除或重建 `data`**；原有學生、聯絡資料、選課、歷年成績皆保留。教師帳號只會在不存在時建立，不會在每次啟動時覆寫聯絡資料。

## 資料與使用限制

關閉後重新啟動仍會保留資料。要回復初始示範資料，請先關閉伺服器，備份後移除專案內的 `data` 資料夾，再重新啟動。

系統只綁定本機 `127.0.0.1`，適合單機課堂展示。使用 scrypt 雜湊、HttpOnly/SameSite Cookie、基本登入頻率限制、來源檢查、參數化 SQL 及 CSP。若要正式部署，需另行設計 HTTPS、安全 Cookie、帳號管理、權限、備份、稽核與真實教務規則；請勿在本系統輸入真實校務密碼或個資。
