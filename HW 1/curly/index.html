功能特色

curl 能做的，
純 Python 也辦得到

⚡

完整 HTTP 方法支援

支援 GET、POST、PUT、DELETE、PATCH 等。提供請求主體時自動切換為 POST。

📋

自訂請求標頭

使用 -H 新增任意數量的請求標頭，可重複使用設定多個。

📦

請求主體傳送

使用 -d 傳送 JSON 或純文字資料，自動偵測並設定 Content-Type: application/json。

🔐

Basic 身分驗證

使用 -u user:pass 進行驗證，自動編碼為 Base64 Authorization 標頭。

↪️

自動跟隨重新導向

使用 -L 自動跟隨 3xx 重新導向，可設定最大跟隨次數。

✨

JSON 自動排版

回應的 JSON 自動格式化縮排，可使用 --no-pretty 關閉此功能。

🔍

詳細模式

使用 -v 查看完整的請求與回應資訊，包含標頭、執行時間與 ASCII 標題圖。

💾

儲存回應至檔案

使用 -o 檔名 將回應主體寫入檔案，非常適合儲存 API 回應結果。

🦾

零外部依賴

僅使用 Python 標準函式庫，不需要 pip install、不需要虛擬環境，Python 3.8+ 即可直接執行。

參數參考

所有可用參數

縮寫 完整參數 說明 預設值
-X--methodHTTP 方法GET
-H--header自訂標頭（可重複）—
-d--data請求主體—
-F--form表單欄位（可重複）—
-u--userBasic 驗證 帳號:密碼—
-L--location跟隨重新導向關閉
—--max-redirs最大重新導向次數10
-o--output儲存主體至檔案—
-i--include顯示回應標頭關閉
-v--verbose詳細輸出模式關閉
—--no-pretty關閉 JSON 格式化關閉
—--timeout逾時秒數30
使用範例

常見應用情境

簡單 GET 請求
bash 
python curly.py https://httpbin.org/get
POST 傳送 JSON 主體
bash 
python curly.py -X POST \
  -d '{"name":"curly","version":"1.0"}' \
  https://httpbin.org/post
自訂請求標頭
bash 
python curly.py \
  -H "Accept: application/json" \
  -H "X-API-Key: mysecretkey" \
  https://httpbin.org/headers
Basic 身分驗證
bash 
python curly.py -u admin:password \
  https://httpbin.org/basic-auth/admin/password
詳細模式 + 跟隨重新導向
bash 
python curly.py -L -v \
  https://httpbin.org/redirect/3
儲存回應至檔案
bash 
python curly.py -o result.json \
  https://httpbin.org/json
快速開始

幾秒內立即上手

01

複製專案

bash
git clone https://github.com/Micha1lyu/curly.git
cd curly
02

立即執行

bash
python curly.py https://httpbin.org/get
03

設定為全域指令（選用）

bash（Linux / macOS）
chmod +x curly.py
sudo ln -s $(pwd)/curly.py /usr/local/bin/curly
# 之後直接使用：curly https://example.com
