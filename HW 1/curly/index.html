Features

Everything curl does,
in pure Python

⚡

All HTTP Methods

GET, POST, PUT, DELETE, PATCH and more. Auto-detects POST when body is provided.

📋

Custom Headers

Add any number of request headers with -H. Repeatable for multiple headers.

📦

Request Body

Send JSON or raw data with -d. Auto-sets Content-Type: application/json for JSON.

🔐

Basic Auth

Authenticate with -u user:pass. Automatically encodes as Base64 Authorization header.

↪️

Follow Redirects

Automatically follow 3xx redirects with -L. Configurable max redirect limit.

✨

Pretty JSON

Response JSON is automatically formatted and indented. Disable with --no-pretty.

🔍

Verbose Mode

See full request and response details with -v. Includes headers, timing, and ASCII banner.

💾

Save to File

Write response body to a file with -o filename. Perfect for API responses and downloads.

🦾

Zero Dependencies

Uses Python standard library only. No pip install, no venv, no hassle. Just Python 3.8+.

Examples

Common Use Cases

Simple GET
bash 
python curly.py https://httpbin.org/get
POST with JSON body
bash 
python curly.py -X POST \
  -d '{"name":"curly","version":"1.0"}' \
  https://httpbin.org/post
Custom headers
bash 
python curly.py \
  -H "Accept: application/json" \
  -H "X-API-Key: mysecretkey" \
  https://httpbin.org/headers
Basic authentication
bash 
python curly.py -u admin:password \
  https://httpbin.org/basic-auth/admin/password
Verbose + follow redirects
bash 
python curly.py -L -v \
  https://httpbin.org/redirect/3
Save to file
bash 
python curly.py -o result.json \
  https://httpbin.org/json
Get Started

Install in seconds

01

Clone the repo

bash
git clone https://github.com/Micha1lyu/curly.git
cd curly
02

Run immediately

bash
python curly.py https://httpbin.org/get
03

Optional: Make it a global command

bash (Linux/macOS)
chmod +x curly.py
sudo ln -s $(pwd)/curly.py /usr/local/bin/curly
# Now just use: curly https://example.com
